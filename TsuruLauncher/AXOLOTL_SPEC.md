# Axolotl UI 复刻规范（从用户截图 + 源码提取）

> 来源：用户提供的 Axolotl 实机截图（极简主页 / 信息主页 / 实验室 / 皮肤选择器 / 实例库 / 创建实例弹窗 / 发现内容）
> 与 `Mystic-Stars/Axolotl` 源码：`apps/app-frontend/src/pages/*`、`components/home/*`、`components/browse/*`、`GridDisplay.vue`、`RowDisplay.vue`、`components/home/home-dashboard.ts`。
> 本文件只记录**结构/交互/视觉规范**，配色数值自拟，不复制其素材。

## 1. 外壳（所有页面共有）

- 左侧**导航栏 64px**：图标 + 10px 文字，选中态为**强调色实心圆角胶囊**（图标反白），未选中为灰色；底部有 `+` 与齿轮两个常驻按钮。
- **顶栏 56px**：左 = 返回/前进箭头 + 页面图标 + 页面标题；右 = 通知铃铛 + 「重新加载以更新」描边按钮 + 「运行中实例」状态 + 最小化/最大化/关闭。
- **右侧信息面板**（可折叠，宽 ~270px，带淡色底 + 左边缘小折角按钮）：
  - 「当前游玩账号」+ 账号下拉卡（头像 + 名字 + 类型）
  - 各页面自己的辅助信息（首页：游玩洞察 / 每日小挑战 / Minecraft 新闻；发现内容：类别 / 更多分类 / 包含内容 / 运行环境 / 游戏版本；实验室：说明）
- **右下悬浮胶囊**：网格/列表视图切换 + 铅笔（编辑布局）两个圆形按钮，固定浮动在内容右下角。
- 卡片：白底、1px 浅描边、圆角 12、几乎无阴影；分组用 8~12 圆角的内嵌浅底块。
- 表单控件用**分段胶囊**（白底容器 + 选中态强调色）；标签用**小灰胶囊**（版本 / 加载器 / 类别）。

## 2. 首页（两态，可切换）

### 2.1 极简主页（minimal）
- 居中：**问候语**（大标题 + 下方一小段强调色短线）
- 一张**横向实例卡**：左 = 实例图标（80px 圆角方图）+ 「还没有实例 / 实例名」；右 = 「+ 创建实例」强调色胶囊按钮（有实例时是「开始游戏」/「安装」+ 圆形列表按钮）
- 无其它小组件；右下角只有编辑/视图悬浮胶囊。

### 2.2 信息主页（dashboard，小组件网格）
- 3 列网格，行高 **160px**，间距 **16px**；小件尺寸档 `1x1 / 2x1 / 1x2 / 2x2 / 3x1 / 3x2`；布局模式 `grid` / `free`；布局可编辑（拖动、改尺寸、删除、添加）。
- 小件种类与默认值：
  - `greeting` 问候语（日期行 + 一句话问候）
  - `calendar` 日历（月历 + 当天游玩记录）
  - `pinned-worlds` 固定的世界（1x2，空状态：图标 + 「将世界标记为收藏后，就会固定在这里。」）
  - `pinned-servers` 固定的服务器（2x2，空状态：图标 + 文案）
  - `pinned-instances` / `instance` 置顶实例（列表 + 播放/安装按钮）
  - `recent-projects` 从最近的项目开始（2x2，空状态：时钟图标 + 「还没有最近活动。」）
  - `news` Minecraft 新闻（右栏列表，缩略图 + 标题 + 日期）
  - `insights` 游玩洞察（「开始游玩后，这里会显示你的统计。」）
  - `daily-challenge` 每日小挑战（标题 + 描述 + 难度点）
  - 悬浮胶囊：➕ 添加小件（弹出选择器）/ ✎ 编辑 / ↺ 重置 / ▦ 网格·自由切换

## 3. 实例库
- 顶部分段胶囊：全部实例 / 整合包 / 服务器 / 自定义
- 列表/网格切换（右下悬浮胶囊或工具栏）
- 空状态：吉祥物插画 + 「未找到实例」+ 「+ 创建新实例」强调按钮
- 卡片悬停显示固定/更多菜单；行内显示加载器 + 游戏版本 + 最近游玩

## 4. 创建实例（弹窗，右侧滑入/居中模态）
- 图标区：默认方块图标 + 「选择图标」+ 「移除图标」
- 名称输入
- **游戏目录**三选一：Axolotl 目录 / 自定义·版本隔离(`.minecraft/versions/实例名/`) / 自定义·版本共享(`.minecraft/`)
- **游戏版本**：分段胶囊（正式版 / 快照 / 愚人节版 / 远古版）+ 版本下拉
- **加载器**：分段胶囊（None / Fabric / NeoForge / Forge / Quilt），不可用项置灰并在悬停时说明原因
- 底部：返回 + 创建实例（强调色）；安装过程用**步骤条 + 进度**（准备 → 版本 JSON → 运行库 → 资源 → 加载器）

## 5. 发现内容（资源浏览）
- 类别胶囊行：整合包 / 模组 / 资源包 / 数据包 / 地图 / 光影包 / 服务器 / 收藏夹
- 第二行：搜索框（占满）+ 「所有来源」下拉 + 翻译按钮
- 第三行：排序方式下拉 + 查看数量下拉 + 网格/列表切换
- 结果行卡片：缩略图 + 标题 + **平台徽标**（Modrinth / CurseForge）+ 简介 + 标签行（加载器 + 类别 + 版本）+ 下载量 + 更新时间 + 「+ 安装」强调按钮
- 底部分页：页码 + 省略号 + 末页
- 右栏筛选面板：类别（可折叠长列表：多人/科技/冒险/魔法/轻量/任务/水槽/挑战/优化/战斗…）、更多 CurseForge 分类、包含内容（搜索 + 客户端/服务端/…）、运行环境、游戏版本

## 6. 实验室
- 标题 + 「N 个工具」+ 搜索框 + 两个筛选下拉（全部工具 / 全部分类）
- 工具卡列表：缩略图（160x90 圆角）+ 标题 + 说明 + 分类标签 + 收藏星标 + 强调色「进入」按钮
- 已有工具：皮肤编辑器 / 渐变文字生成器 / 种子地图 / 投影工坊 / 模组翻译 / 配方生成器 …

## 7. 皮肤选择器
- 顶部：分段胶囊（已保存皮肤 / 官方皮肤）+ 「+ 创建皮肤」强调按钮
- 左：3D 皮肤预览（可拖动旋转）+ 「编辑皮肤」按钮
- 中：皮肤卡片网格（已保存列表 + 「添加皮肤 拖放」虚线卡）
- 右栏：兼容性说明

## 8. 我们（Tsuru Launcher）的落地顺序

1. **外壳**：右侧信息面板（可折叠）+ 右下悬浮胶囊 + 顶栏按钮规范 + 分段胶囊/标签控件样式
2. **首页两态**：极简（默认）+ 信息主页（小组件网格，含日历/固定世界/固定服务器/最近项目/新闻/洞察/每日挑战）
3. **发现内容**：类别胶囊 + 排序/数量/视图切换 + 分页 + 行卡片（平台徽标/标签/下载量/更新时间）+ 右栏筛选面板
4. **创建实例向导**：图标/名称/游戏目录三选一/版本类型分段/加载器分段 + 步骤条安装进度
5. **实例库**：分段胶囊 + 空状态插画 + 行卡片
6. **实验室**：搜索 + 分类筛选 + 缩略图卡列表（自有工具集）
7. **皮肤**：预览 + 已保存/官方 + 拖放添加
