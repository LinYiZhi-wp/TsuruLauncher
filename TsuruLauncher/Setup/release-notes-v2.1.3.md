## 🔒 关于账号数据安全

发布包经过**自动泄露审计**（`Setup/audit-package.py`），确认不含任何账号数据：

- 账号只存在本机 `%APPDATA%\TsuruLauncher\config.json`，**不在程序目录**，
  所以打包 / 更新 / 重装都不会带上它
- 审计逐字节扫描 `publish/` 和 zip（含 UTF-8 + UTF-16 两种编码），
  比对**账号 UUID / 用户名 / 各类令牌 / 自有皮肤 SHA1**，并有**阳性对照**防止假阴性
- 打开发版统一走 `Setup/build-release.py`：干净发布 → 审计 → 打包 → 再审计，
  审计不过直接中止，不会产出包

> ⚠️ 注意：**不要**把 `%APPDATA%\TsuruLauncher\` 这个目录分享给别人（那里面才是账号）。
> 安装目录（`C:\Program Files\Tsuru Launcher`）是干净的，可以放心分享。

## 更新内容

### 🐛 重要修复：账号数据

- **账号不再只存一个** —— 之前切换账号会把上一个**直接覆盖**，重启后只剩最后用的那个。
  现在存整个账号列表 + 「当前是谁」的标识，切换多少个都留得住。
  旧配置会**自动迁移**，不用手动处理。
- **新增「导出 / 导入账号」**（设置 → 账号）—— 换电脑时导出成 json，在新机器导入即可，
  不用重新登录。导入按 Uuid 合并，不会覆盖现有账号。
- **配置写入改为原子替换 + 备份** —— 之前直接覆盖写，写到一半被杀进程 / 磁盘满
  会让 config.json 变成半截 JSON，下次启动静默重置，账号和设置全丢。
  现在写临时文件再原子替换，并保留 `.bak`，主配置坏了自动回退。

### 🐛 其他修复

- **皮肤页拉取失败时不再空白** —— 网络/接口挂掉时退回本地备份显示，
  并标注「离线缓存」，不再出现「皮肤全没了」的假象
- **上传皮肤后不会闪回旧皮肤** —— Mojang 档案接口有延迟，改为先用本地结果更新界面
- **删除皮肤 / 移除 Mod 加确认**，删除进回收站而不是永久删除
- **离线账号不再显示正版账号的皮肤历史**（备份按账号分目录存放）
- **修复 3 处可能导致崩溃的未捕获异常**（拖放导入、登录窗口初始化、设置开关）
- **修复多处「悬停没反应」** —— 有几处 hover 色和基础色是同一个画刷

### 🐛 v2.1.3 补充修复

- **修复「简洁模式 ⇄ 网格模式」切换卡死** —— 首页小组件网格重排 / 分段指示块
  在尺寸抖动时会进入布局死循环，把 UI 线程占满。现在两处都加了**频率熔断**：
  1 秒内超过阈值就停手，宁可布局差一点也绝不卡死。
- **修复浅色模式下文字看不清** —— 导航栏未选中项、顶栏状态文字、小标签
  之前用的是最淡的 `TextDim`（本来是给「禁用」态用的），浅色背景下几乎与背景同色。
  已全部换成 `TextSecondary` / `TextTertiary`。
- **版本号不再写死** —— 之前 XAML 里硬编码了 `v2.0.0`，导致 v2.1.0 的包里
  仍显示 v2.0.0。现在从程序集读取。

### 🐛 v2.1.3 补充修复

- **修复「刷新 / 下载进度」等按钮文字完全看不见** —— 根因是「用两层 ContentPresenter
  做文字色交叉淡入」这个手法有个隐藏前提：**一个 UIElement 只能有一个父节点**。
  内容是**字符串**时两层都能渲染；内容是 `StackPanel` / `TextBlock` 这类 UIElement 时，
  它只会挂到其中一层上（还正好是 `Opacity=0` 的那层），文字就彻底消失了。
  受影响的是「刷新 / 下载进度」和分页页码，已改成单 ContentPresenter。

### ✨ 动画与交互

- **全局清理了 40 处硬切**，所有状态切换（页签、选中、悬停、按下、禁用、展开/收起）
  现在都有过渡动画，不再有「啪」一下的瞬时变化
- 卡片悬停上浮、选中描边淡入、对勾缩放弹出、文案切换淡入

### ⚡ 性能

- **缩略图缓存**：切换页签不再把整个皮肤库的 3D 缩略图重渲一遍（热态快约 4.7 倍）
- **小组件网格重排合并**：启动时 5 次重排 → 1 次，首屏快约 30ms
- **切页签不再重复请求网络**（加 10 秒 TTL），皮肤 PNG 加解码缓存
